# Contributing

Thanks for helping improve this list.

## What belongs here

- Resources that teach or support **AI security** work: attacking, defending or evaluating AI systems.
- Hands-on material is preferred: labs, CTFs, tools, reproducible research.
- Free resources are preferred. Paid ones are fine if they are clearly worth it.

## What doesn't

- Marketing pages and vendor content with no technical substance.
- Abandoned tools, unless they have historical or educational value. Mark those as archived.
- Duplicates of resources already listed.

## How to add a resource

1. Put it in the most specific section that fits.
2. Use the format: `[Name](link): one sentence on what it is and why it's useful.`
3. Check that the link works and points to the canonical source.
4. For GitHub projects, check that the repository is maintained, or mark it `Archived`.
5. For papers, use the arXiv abstract page (`/abs/`), not the PDF.
6. Open a pull request with a short explanation.

## Reporting dead links

Open an issue or a pull request that removes or replaces the link.
